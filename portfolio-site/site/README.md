# Siddhant Virmani Portfolio

Static site: no build step or dependencies.

Files: index.html, photo.jpg, Siddhant_Virmani_Resume.pdf (keep all three in the same folder).

Run locally: open index.html in a browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000

Deploy: upload this folder to Netlify Drop, Vercel, or GitHub Pages (repo Settings > Pages). The Resume buttons download Siddhant_Virmani_Resume.pdf.

Edit: names and text are in index.html; project repo links are in the REPOS block at the top of the script.
